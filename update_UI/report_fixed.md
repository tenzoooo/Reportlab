# 5. 実験結果

## 実験 5.1：IC–VCE特性の測定

回路は図4.1のエミッタ接地回路を用いて構成した。電源Aを電流源として使用し、電源BでVCEを0 Vに設定した後、電源AをONにしてIBを0、20、40、60 μAにしたときのICおよびVCEを記録した。VCEの変化は0–0.5 Vを0.05 V刻み、0.5–2 Vを0.5 V刻み、2–10 Vを2 V刻みで繰り返し測定した。 測定で得られた値を表 5.1.1.1に整理した。 表より、系1のICは概ね0.006〜0.009 mAと小さく、系4では最大で約6.85 mAに達した。 VCE≳1 VではICは5.51〜6.83 mA（変動幅1.31 mA、±10.6%程度）であり、「ほぼ一定」とは言い切れない変動が残る。 なお、表 5.1.1.1には一部未記録（空欄）のデータが含まれる（例: 目標VCE=1.5, 2.0088, 3.9996, 6.0013）。この欠損により、欠測区間の傾向判断は限定的である。 目標VCEと実測VCEの差は最大でも約8.52 Vであった。 同データの特性を図 5.1.1.1に示す。

VCE≈1 VにおけるICはIB=60 μAで約0.008 mA、系2で約2.85 mA、系3で約3.73 mA、系4で約5.51 mAとなった。 系4ではVCE≳1 VでICは5.51〜6.83 mA（変動幅1.31 mA、±10.6%程度）であった。 なお、一部データ欠測（合計6点）があり、欠測区間の傾向判断は限定的である。 以上より、この結果は実験書に示される「能動領域ではICがVCEにほぼ依存しない」という特性と部分的に一致と判断できる（一致しきらない要因は考察で検討する）。
